# 星火牌局的素材来源

**没有任何外部素材。** 仓库里没有图片、字体、音频文件,构建产物里也没有:

- 卡面徽记:**36 张可收集卡 + 1 张召唤物 + 3 位英雄,共 40 个独立的内联 SVG 图案**(`src/art.ts`),每张卡一个键、一条手写 path,不共用、不重复;
- 图案配色:阵营色(熔火工坊 / 霜林哨站 / 暮影集市 / 中立)与稀有度(普通 / 稀有 / 史诗)全部由 CSS 变量控制,亮暗两套各一份,史诗卡带光晕;
- 动效粒子:出牌、攻击、受伤、治疗、圣盾、死亡、亡语、烧牌都是运行时生成的 CSS 粒子(小方块/圆点),没有图片资源;
- 音效:**全部由 `src/audio.ts` 用 WebAudio 现场合成**(振荡器 + 包络 + 程序生成的白噪声),按键、出牌(随从/法术不同音色)、攻击、受伤、治疗、圣盾碎、死亡、亡语、战吼、嘲讽落地、冲锋、抽牌、烧牌、疲劳、胜负各一种;
- BGM:三套卡组各一段很轻的合成循环(五声音阶 + 低音打底),随对局开始/暂停/切后台启停;
- 字体:用系统自带字体(宋体系列 / 苹方 / Noto Sans CJK),不下载、不打包任何字体文件;
- 网络:运行时没有任何 fetch / XHR / 外部 CDN 请求;对局、电脑 AI、平衡模拟、存档读写的逻辑都在本地算。

世界观、卡牌名字、风味文案、界面布局都是原创,没有使用任何商业卡牌游戏的名字、卡牌、角色、素材或界面。
