# 星火牌局的素材来源

**没有任何外部素材。** 仓库里没有图片、字体、音频文件,构建产物里也没有:

- 卡面图案、英雄头像、阵营徽章、背景星火:全部是 `src/art.ts` 里手写的内联 SVG path + CSS 渐变与动画;
- 音效:全部由 `src/audio.ts` 用 WebAudio 现场合成(振荡器、包络和程序生成的白噪声),没有音频文件;
- 字体:用系统自带字体(宋体系列 / 苹方 / Noto Sans CJK),不下载、不打包任何字体文件;
- 网络:运行时没有任何 fetch / XHR / 外部 CDN 请求;对局、电脑 AI、存档读写的逻辑都在本地算。

世界观、卡牌名字、风味文案、界面布局都是原创,没有使用任何商业卡牌游戏的名字、卡牌、角色、素材或界面。
