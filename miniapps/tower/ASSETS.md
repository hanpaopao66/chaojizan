# 瓜田防线的素材来源

**没有任何外部素材。** 仓库里没有图片、字体、音频文件,构建产物里也只有 html/js/css/json:

- 场景、土路、木桩、七种塔、九种虫、大西瓜、粒子与飘字:全部是 `src/render.ts` / `src/art.ts`
  用 Canvas 2D 现场画出来的(色块、圆角矩形、贝塞尔曲线、程序化噪声点),没有一张位图;
- 音效与三套主题 BGM:全部由 `src/audio.ts` 用 WebAudio 现场合成(振荡器、包络、程序生成白噪声),
  没有 mp3/ogg/wav 文件;
- 字体:用系统自带字体(苹方 / 思源黑体 / Noto Sans CJK),不下载、不打包任何字体文件;
- 网络:玩法不联网,运行时没有任何 fetch / XHR / WebSocket / CDN 请求,断网也能玩;进度保存走超级赞宿主提供的云存储。

世界观(瓜田、大西瓜、七种菜园塔、虫巢)、地名、塔名、虫名、关卡、数值和界面都是为超级赞原创的;
没有使用任何商业塔防游戏(包括《保卫萝卜》)的名字、角色、关卡、美术、数值、音效或界面。
塔防这个品类本身是公共玩法,不构成任何商业作品的复制。
