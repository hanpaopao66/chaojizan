## 二、审核测试账号

审核员(尤其苹果海外审核)收不到国内短信,平台提供**固定验证码白名单**:

- 服务端 `.env.prod` 配置 `SMS_REVIEW_ACCOUNTS=手机号:固定码`(逗号分隔多个);
  命中的号码不真发短信,登录界面输入固定码即可通过。固定码不进仓库,
  以部署机实际配置为准(建议格式:`13900000001:246810`)。
- 提审前用 `python -m scripts.demo_seed` 保证演示商家/团购券/酒店数据就绪,
  并给测试账号预置 1-2 笔历史订单和一个演示城市的收货地址,看起来像真实用户。

**粘贴到审核备注的模板**(手机号/验证码按 .env.prod 实际值替换):

```
测试账号:139 0000 0001
```

## 三、核心体验路径(照此顺序过一遍)

1. **首次启动**:隐私弹窗(可查看《用户协议》《隐私政策》全文)→ 同意进入;
2. **游客浏览**(无需登录):首页附近商家 → 商家详情/菜品 → 搜索 → 超值团购 → 住宿;
3. **注册/登录**:任一需登录动作(结算/收藏/我的)触发登录页,页内有明确的
   「登录 / 新用户注册」双入口;用测试账号+固定码登录;
4. **下单**:选商家加购 → 结算(选/填演示城市收货地址)→ 提交订单 → 模拟支付 →
   订单详情可见分账明细(商家/骑手/平台)与配送状态;
5. **权限申请**:首页定位、更换头像(我的-头像)时,先弹中文用途说明,
   点"去授权"才出系统弹窗;拒绝后功能有兜底、App 正常可用;
6. **消息中心**:首页右上角铃铛(平台公告 + 订单通知);
7. **帮助与反馈**:我的 → 帮助中心(FAQ)/ 意见反馈 / 联系平台客服;
8. **设置与关于**:我的 → 设置(通知开关/清缓存/检查更新)→ 关于我们
   (版本/公司/电话/邮箱/备案号/协议);
9. **注销账号**:我的 → 注销账号 → 后果说明 → 勾选确认 → 倒计时二次确认 →
   注销成功回游客首页(有在途订单会被拦截并提示原因)。

商家端/骑手端(B 端工具 App):登录后于「店铺」tab /「钱包」tab 底部可达
协议全文、退出登录与注销账号;如需商家端/骑手端测试账号,同样走白名单机制配置。

## 四、权限与隐私速查(审核员常问)

| 权限 | 申请时机 | 用途 |
|---|---|---|
| 位置 | 进首页附近商家/选收货地址时 | 展示附近商家、算配送费;拒绝则展示演示区域 |
| 相册 | 更换头像/上传凭证时 | 选取图片上传 |
| 相机(商家/骑手端) | 扫码核销/拍摄凭证时 | 核销团购券、送达凭证 |
| 通知 | 首次进入订单场景 | 订单状态提醒 |
| 蓝牙(商家端) | 连接小票打印机时 | 打印订单小票 |

- 所有权限均"先应用内说明目的、用户同意后再调系统弹窗",拒绝不影响其他功能;
- 第三方 SDK 仅极光推送(JPush),已在隐私政策公示(含主体/信息/目的/链接);
- 微信支付为服务端接口方式,App 未内嵌支付 SDK;审核期间支付走模拟支付,
  不产生真实扣款;
- 无广告、无诱导分享、无自动续费。
