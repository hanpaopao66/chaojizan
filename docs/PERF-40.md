# 消息与视频 · 性能与容量(DEV-PROMPTS-40 #372)

目标(部署机 4 核):同时在线 2,000 连接;发消息 p95 < 150ms;会话列表 p95 < 200ms;视频卡片流 p95 < 200ms。

## 怎么测的

脚本 `scripts/loadtest_chat.py`(写法照仓库的压测经验:压测端自己会先堵、会说谎):

- 8 个进程分摊 2,000 条 `/ws/v2` 连接(200 个账号,一号多设备),每条 25 秒一个 ping,保持到压测结束;
- 背景流量:另一个进程**开环**按每秒 20 条发私聊消息(不等上一条回来),事件扇出到在线的连接;
- 延迟**只看旁路探针**:独立进程、独立账号,串行地发一条消息并在对方的连接上等到它、拉会话列表、拉视频推荐,每秒一轮;
- 结果同时报:实际连上多少、失败多少、真实每秒发了多少、连接进程一共收到多少帧。

## 结果(2026-09-13,开发机,不是部署机)

环境:MacBook(Apple Silicon)上同时跑压测端和服务端,服务端是**单个** uvicorn 进程(不开 reload)、PostgreSQL / Redis 在本机 docker 里;
库里是开发数据(几百个测试账号、上千个会话、几十个视频)。**这台机器比部署机强、但压测端和服务端抢同一台机器的 CPU**,
两个因素方向相反,数字只能当量级看,上线前要在部署机上按同样的参数再压一次。

| 场景 | 连接 | 背景流量 | 发消息 p50 / p95 / p99 | 发出 → 对方收到 p95 | 会话列表 p95 | 视频推荐 p95 |
|---|---|---|---|---|---|---|
| 陆续上线(`--ramp-ms 20`,每进程 250 条摊在 5 秒里) | 2,000 / 2,000,失败 0 | 1,800 条全成功,20.0 条/秒,扇出 46,127 帧 | 23.9 / 35.7 / 111ms | 35.7ms | 27.0ms | 43.7ms |
| 重连风暴(`--ramp-ms 5`,2,000 条挤在 1.3 秒里) | 1,906 连上,94 条 20 秒内没握上手 | 1,800 条全成功,20.0 条/秒,扇出 43,917 帧 | 25.1 / 53.0 / 846ms | 53.0ms | 23.8ms | 48.8ms |

目标:发消息 p95 < 150ms、会话列表 p95 < 200ms、视频推荐 p95 < 200ms —— 两个场景的 p95 都达标。
「发出 → 对方收到」和「发消息」几乎一样:事件在提交之后当场推,对方连接上收到的时候,发的人的 HTTP 响应还在路上。

## 结论和改动

- 稳态目标(2,000 在线、发消息 / 会话列表 / 视频推荐的 p95)在单进程上达标,余量大;
- **重连风暴**是这一轮找到的真问题:服务端一重启,所有客户端同一秒断线,原来的退避是确定的 1 / 2 / 4 / 8 秒,
  大家又在同一时刻一起重连。压测里 2,000 条在 1.3 秒内同时握手,有约 5% 在 20 秒内没握上手(`TimeoutError`)。
  客户端退避改成 0.5–1.5 倍抖动(`chat/realtime.dart`),把同一波重连摊开;
- 会话列表是固定几条批量查询(`chat_view.dialogs`:会话、成员、最后一条消息、私聊对方、小群已读各一次),不随会话数 N+1;
- 消息分页走 `(chat_id, seq)` 唯一索引;计数(未读、浏览量)是增量写,不在读的时候现算。

## 部署机上复测

```bash
# 部署机上起一个不对外的实例(和线上同一个库会写进测试数据,用预发库)
ulimit -n 10240
cd server && DATABASE_URL=<预发库> .venv/bin/python -m uvicorn app.main:app --port 8031 &
# 压测端放在另一台机器上跑,别和服务端抢 CPU;生产环境没有短信验证码回显,用 --tokens 传现成的 token
python scripts/loadtest_chat.py --api http://<部署机>:8031 --conns 2000 --rate 20 --duration 120 --ramp-ms 20 --tokens tokens.json
python scripts/loadtest_chat.py --api http://<部署机>:8031 --conns 2000 --rate 20 --duration 120 --ramp-ms 5  --tokens tokens.json   # 重连风暴
```
