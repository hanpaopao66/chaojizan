## 品牌人格

劳动者互助平台:**真诚、利落、有烟火气**。
不端着(不是精英范),不喊口号(信任靠体验),不装可爱(工具要利落)。
对外传播可以有立场和火气(第一战/打穿一个再打下一个),产品内保持克制——
**App 里不贴战斗口号,让用户在账单里自己撞见证据。**

### 为什么破例引入一个蓝(#136)

整套色板里只有这一个蓝,而且只给"点了会离开当前页"的字。

`clay` 是**行动色**,用户读作"这是本产品的按钮";协议链接要传达的是
"这是一条通向别处的链接" —— 中文 App 里这个信号就是蓝色。拿橘色标链接,
用户只会当成一句被强调的话,不会想到能点。而应用商店审核恰恰要求
第三方 SDK 的隐私政策链接**可点可达**,印在那儿点不动等于没给。

取值不是随手挑的:常见的 `#1677FF` 在骨白底上对比度只有 **3.53**,过不了 AA。
现取值浅色态 5.84 / 深色态 6.9~8.5(实测,含账目深台面)。

## 频道色:平台色与频道色是两回事(#132)

聚合平台的频道是**开放集合**,注册表在
`packages/shared/lib/src/channels.dart`,**新增频道只改那一处**。

**`clay` 黏土橘是平台色,不属于外卖。** 平台身份、承诺条、跨频道主 CTA
(支付/确认下单/提交)用它。如果外卖独占品牌色,后进的每个频道在视觉上
都是二等公民 —— 而聚合平台的前提是各频道地位平等,外卖也只领一个频道色。

频道色取自 `channelTones` 的 **8 个受限色槽,按顺序领用,不许自由取色**。
不给自由取色是有意的:聚合平台变成彩虹糖,就是从"这个频道想要个亮蓝"开始的。
槽位用尽再讨论扩板,那时至少是一次有意识的决定。

| 槽 | 浅色 | 深色 | 现由谁领用 |
|---|---|---|---|
| 0 | `#B4553B` | `#D98567` | 点外卖(碗) |
| 1 | `#4E6B4F` | `#8FB08D` | 住宿(宿) |
| 2 | `#A6763E` | `#D2A86C` | 超值团购(券) |
| 3–7 | `#4A6670` `#6B5B7B` `#7A6248` `#3F6B63` `#8A5A5A` | 见 `brand.dart` | 未领用 |

**能出现在哪(白名单)**:频道入口卡的字符与细节、频道内页头部的 3px 标识条
(`SzChannelBar`)、频道归属 chip(`SzChannelChip`)、该频道空状态插画着色。

**不能**用于实底主 CTA —— 那是平台色的位置,「一屏一个实底按钮」的纪律
不因分频道而破。**不能**用于金额与状态 —— 那是 `earn` / `hold` / `danger` 的语义位。

`channelOf()` 取不到时**返回 null 而不是抛异常**,`channelColor()` 回退平台色:
服务端将来下发一个客户端还不认识的新频道时,页面要正常显示而不是白屏 ——
这是聚合平台最容易翻车的地方,有测试守着。

**字体**(2026-07-29 对齐后):拉丁与数字打包两款 OFL 子集,中文一律回落系统字。

| 用途 | claude.ai 用的 | 我们用的 | 选它的理由 |
|---|---|---|---|
| 衬线 · 数字 | Galaxie Copernicus | `SzSerif` = **Literata** | Copernicus 是受 Plantin 影响的过渡期衬线,Literata 同属这一脉 |
| 无衬线 · 拉丁词 | Styrene B | `SzSans` = **Space Grotesk** | Styrene 的几何无衬线特征,公认最接近的 OFL 替代 |

Copernicus 与 Styrene 都是商用授权,打不进开源仓;npm 上那个第三方
`anthropic-fonts` 包标 MIT 是无效授权,不能用。取法:正文数字 `szFigure()`
(旧式数字)、竖排对齐的金额 `szMoney()`(等宽)。
详见 `packages/shared/assets/fonts/README.md`。

**按钮圆角**:8 的圆角矩形,不是全胶囊——claude.ai 的按钮是圆角矩形。
chip 仍是胶囊(那是标签不是按钮)。

**动效**:只用 ease-out 一族,不用 elastic / back 这类带回弹过冲的曲线;
UI 过渡 160–260ms,唯一的长动画是分账条的占比展开(450ms)。
所有位移与缩放动画都尊重系统「减弱动态效果」。

两层的关系:传播层负责喊话,产品层负责干活。**App 内出现品牌渐变的地方
只剩一处:Logo 本身**——承诺卡在第八辑改成了 `claySoft` 淡底,

透明不靠说,靠每一处钱的颜色一致。

## Logo(v2 定稿:赞手 + 透明账目)

**竖起的大拇指 = 「赞」**(对应品牌名,群众互相帮衬的姿态);
**手掌三道横线 = 指缝,也是摊开的账单**(商家/骑手/平台三方分账一目了然);
**金黄袖口 = 配送费与烟火气**。渐变圆角底,圆角率 116/512 ≈ 22.7%。

## 布局原则(商业化 ≠ 花哨)

1. **首屏第一交互给搜索**:大搜索框直接可见,不藏在图标里
2. **不放口号横幅**:三原则的正确表达是——
   订单详情里可查的「钱去哪了」卡、店铺页的「本店仅被抽成 5%」实数、
   券详情里的「未使用随时全额退」按钮。让用户撞见,而不是被告知
3. **卡片克制**:圆角 14、无阴影(elevation 0)、留白撑质感
4. **促销不抢行动**:满减标签用琥珀描边小签,主按钮永远是最橙的那个

## 三端密度分化(#134)

三端不是同一群人在同一种姿势下用的:

- **用户端**是「逛」—— 躺着刷,单手,不急。信息可以密,一屏多放几条才好逛;
- **商家端**是「扫一眼就处理」—— 收银台前手忙,后厨油烟、光线不好;
- **骑手端**是「戴手套单手点」—— 电动车边上、日晒下、有时在雨里。

所以定两档密度 `SzDensity`(`packages/shared/lib/src/brand.dart`):

| | `browse`(用户端) | `operate`(商家端 / 骑手端) |
|---|---|---|
| 主按钮最小高 | 48(Material 基线) | **56** |
| 次按钮 / 文字按钮 | 44 | 50 |
| 图标按钮命中区 | 44 | **52**(Flutter 默认才 40) |
| 列表行竖直内边距 | 4 | 10 |
| 正文字号 | 基准 | 基准 **+1** |
| `visualDensity` | standard | `vertical: 1` |

实测渲染高度(`packages/shared/test/density_test.dart` 量的是
`tester.getSize()`,不是主题字段):

| | browse | operate |
|---|---|---|
| FilledButton | 48 | 60 |
| OutlinedButton / TextButton | 48 | 54 |
| IconButton | 48 | 52 |
| ListTile(两行) | 72 | 76 |

三条纪律:

1. **只在主题层做,不去改页面里写死的 padding。** 全仓有 44 处
   `kPagePad` / `kCardPad` 调用点,逐个改代价大、会丢 `const`,而且下次
   新写的页面照样漏。主题会自动传播到所有按钮、列表行、输入框。
2. **`browse` 是默认值。** 新页面忘了传参,拿到的是用户端口径 ——
   宁可漏掉商家端的加大,也不要让用户端莫名其妙变松。
3. **密度不许碰颜色。** 两档密度的 `clay` / `paper` / `ledger` /
   `channelTones` 必须逐一相等,否则三端会长得不像一家(有测试守着)。

`kPagePad = 18` / `kCardPad = 14` 三端仍然共用 —— 它们是**版心**,
改了三端的页面骨架就不一样了,那是另一件事,不是密度。

## 账目专属表面(#133)

「钱去哪了」「平台账本」这类**可查账**的地方用 `SzLedgerCard`,不是普通 `SzCard`。
账目透明是这个产品唯一抄不走的差异点,不该和别的卡片长得一样。

手法是**深浅两态用不同的逻辑**,不是简单套一个深色:

- 浅色页面上,它是深色台面 —— 靠反差从骨白里"硬"地凸出来;
- 深色页面上,它比页底更深 —— 一口下沉的井。

深色态还必须加一道 `Color(0x1FFFFFFF)` 描边:实测台面与页底的明度只差
**1.10**,光靠颜色分不出这是两层(浅色态的差值是 14.35,不需要描边)。

`SzLedgerCard` 内部会把 `SzColors` 整体换成深色态,子组件读 `sz.ink` /
`sz.earn` / `sz.hold` 时自动适配,**调用方一行不用改**。台面上的文字对比度
实测:ink 14.61/16.79、earn 6.96/7.99、hold 7.59/8.72、clay 6.36/7.31,全部过 AA。

## 插画(brand_art.dart)

空状态不用灰图标,用有温度的小画。统一手法:暖色大圆底 + 圆头描边图形 +
品牌橙点缀一笔 + 不对称装饰小点。五款:碗(没商家/没菜)、票券(没券)、
单据(没订单)、断线云(没网)、放大镜找碗(搜索无结果)。
`EmptyState` 按图标语义自动匹配,调用方零改动。

## 微动效(ui_bits.dart)

原则:**反馈要快(≤200ms),装饰要省**。动效是确认操作被响应,不是表演。

| 场景 | 动效 | 时长 |
|---|---|---|
| 列表首屏进场 | FadeSlideIn:淡入+上滑,逐项错开 45ms,仅前 8 项 | 320ms |
| tab 切换 | 淡入 + 1.5% 微上滑 | 160ms |
| 空态插画/成功图标 | PopIn:0.6→1 弹性缩放 | 450ms |
| 购物车角标 | 数量变化弹跳(elasticOut) | 350ms |
| 结算合计 | 金额上滚换字 | 200ms |
| 骨架屏 | 透明度呼吸 | 900ms 循环 |
| nav 图标 | 描边→实心切换(M3 自带指示) | 系统 |
