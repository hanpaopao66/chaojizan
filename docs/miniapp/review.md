# 审核规范

## 流程

1. 你提交版本,写上给审核员的测试说明;
2. 审核员在模拟器和真机里按[审核清单](#审核清单)逐项过,看得到这个版本和上一个通过版本的**差异**
   (文件、`superz.json`、服务器域名、能力、展示信息);
3. 结论只有两种:**通过**,或**驳回**(必带[原因代码](#原因代码)和写给你的说明);
4. 通过后你点发布(或打开「审核通过后自动发布」)。

平台不承诺具体审核时限;审核时长的中位数、每月提交 / 通过 / 驳回数在[透明中心](/transparency)照实公示。

## 前提

- 开发者认证通过(个人实名或企业认证);
- 接受了最新版的开发者规则;
- 展示信息完整:名称、图标、一句话介绍、描述(≥ 10 字)、隐私政策(≥ 20 字,不收集也要写明)、数据声明。

上架后改名称、图标、描述、隐私政策,改动**随下一个版本送审**,发布时生效 —— 过审的应用不能当场改成别的东西。

## 审核清单

第 1 版,十项全部确认才能给「通过」:

1. 能打开,核心功能可用(R101)
2. 与名称、描述、截图一致(R102)
3. 不是空壳、测试页、半成品(R103)
4. 内容合法,无色情、赌博、诱导分享(R201–R206)
5. 不引导站外交易、不绕开平台规则(R207)
6. 隐私政策与数据声明齐全且与实际一致(R301–R303)
7. 小游戏无内购、无广告(R402)
8. 不仿冒平台界面(R501)
9. 无恶意代码、挖矿、刷量(R502)
10. 网络请求只去声明过的服务器域名(R503)

## 原因代码

驳回和处罚一律带代码,和后台、透明中心是同一张表。

| 码 | 原因 | 常见情形 | 不算违规的例子 |
|---|---|---|---|
| R101 | 打不开或核心功能不可用 | 白屏;主要按钮点了没反应;依赖的后端挂了 | 某个次要功能要登录你自己的账号(写在测试说明里) |
| R102 | 与名称、描述、截图不符 | 叫「记账本」,打开是小说 | 功能比描述多 |
| R103 | 空壳、测试页、半成品 | 只有一行 hello;大部分按钮是「敬请期待」 | 功能少但完整 |
| R201 | 违法违规内容 | 违禁品、侵犯他人权益的信息 | — |
| R202 | 色情低俗 | 露骨内容、擦边标题 | — |
| R203 | 赌博、彩票、博彩 | 押注换现金或可兑换的虚拟币 | 纯娱乐、没有任何兑换的抽签 |
| R204 | 诱导分享、诱导关注、诱导下载 | 「分享 3 个群才能继续」「关注公众号解锁」 | 一个普通的分享按钮 |
| R205 | 虚假宣传、夸大功效 | 「包治百病」「稳赚不赔」 | — |
| R206 | 侵害未成年人权益 | 引导未成年人消费、不良内容 | — |
| R207 | 引导站外交易、绕开平台规则 | 放收款码、引导加私人微信交易 | 链接到你的官网(经「即将离开超级赞」确认) |
| R301 | 隐私政策缺失或与实际不符 | 没写隐私政策;写了不收集却在收集 | — |
| R302 | 超出声明范围收集信息 | 声明只存笔记,却在上报设备信息 | — |
| R303 | 未经同意获取敏感信息 | 骗用户手输身份证号、定位 | 用户主动填写且在隐私政策里写清楚的 |
| R401 | 缺少类目要求的资质 | 医疗、金融、新闻等需要资质的内容 | — |
| R402 | 游戏缺少版号、含内购或广告 | 本期小游戏不允许内购和广告 | 免费单机 |
| R501 | 仿冒平台界面、钓鱼 | 画一个像超级赞支付页的界面;名称带「官方」「客服」 | — |
| R502 | 恶意代码、挖矿、刷量 | 偷偷挖矿、刷接口、混淆后的可疑脚本 | 正常压缩过的构建产物 |
| R503 | 请求了未声明的服务器域名 | 页面去连后台没声明的域名 | 先在「开发设置」里声明 |
| R601 | 商标、著作权侵权 | 用别人的商标、盗版素材 | 有授权并能出示 |
| R701 | 其他 | 以上都不贴切时用,**必须写明具体说明** | — |

## 隐私要求

- 每个应用都要有隐私政策和数据声明(收集什么、为什么);
- 你只能拿到 `open_id`,拿不到手机号 —— 不要在页面里要用户手输手机号、身份证号来「验证身份」;
- 昵称头像只能经 `requestProfile` 由用户同意后拿;
- 模板见[开发者协议与隐私政策模板](agreement.md)。

## 申诉

- 对驳回、处罚(暂停、移除、紧急隔离)、能力驳回、认证驳回,**7 天内可以申诉一次**;
- 在后台「审核记录」里点「申诉」,写清楚理由和证据;
- **系统强制换一名审核员复核** —— 原结论人处理不了你的申诉;
- 申诉成立 = 撤销原结论,状态真的回来(驳回的版本回到「审核通过」、暂停的应用恢复……)。
  移除是终态,申诉成立是唯一回来的路,回到「下架」由你决定何时上架。
