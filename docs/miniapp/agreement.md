# 开发者协议与隐私政策模板(草案)

> **草案**:以下条款在法务定稿前可能调整。每次调整都记在规则留痕里([开发者规则](/developers/rules)页的修订记录),
> 并且要你重新接受后才能继续提交审核。规则页里的每个数字都由代码常量生成,和这里说的一致。

## 开发者协议要点(草案)

1. **你是独立的个人信息处理者**。你的应用收集、使用用户信息,由你对用户负责;平台对你提供托管和身份服务,
   不替你的数据处理背书;
2. **你拿到的身份**只有按应用隔离的 `open_id`(和用户同意后的昵称头像)。不得尝试反推用户的平台账号、手机号,
   不得和其他应用串联同一个人;
3. **必须有隐私政策和数据声明**,并与实际一致;超出声明收集按 R302 处理;
4. **本期不得**收款、内购、放广告、引导站外交易;
5. **不得仿冒**超级赞或其他品牌的界面、名称;
6. **托管的版本不可变**:审核通过的就是上线的那一份;你可以随时发新版本、回滚到历史版本;
7. **处罚**:暂停、紧急隔离、移除,每一项都带原因代码和说明;7 天内可申诉一次,由另一名审核员复核;
8. **数据**:云存储里的用户数据你的服务端不能直读;应用被移除后,用户数据保留 30 天供导出,然后清除;
9. **费用**:发布免费。平台不出售排名、推荐位,也不接受为此的任何对价;
10. **退出**:你可以随时移除应用、注销开发者账号(名下应用要先移除)。

## 隐私政策模板(草案)

把下面这段改成你自己的,贴到后台「展示信息 → 隐私政策」。**写实际情况**,不收集的项就写不收集。

```text
「<应用名>」由 <开发者名> 提供,运行在超级赞小程序平台上。

我们收集:
- <例:你写下的笔记内容>,用于 <例:保存并在你的设备间同步>;
- (如有)你授权的昵称和头像,用于 <用途>。
我们不收集你的手机号、定位、通讯录;你在超级赞的账号信息我们拿不到。

存储:数据存在 <超级赞云存储 / 我们自己的服务器(地区)>。<如用超级赞云存储:按应用和你的账号隔离,
我们的服务端不能直接读取。> <如用自己的服务器:写明保存期限和安全措施。>

共享:我们不向第三方出售或提供你的信息。<如有必须的第三方服务,逐一列出。>

你的权利:你可以在超级赞「我的 → 设置 → 小程序授权与数据」里导出、清空数据,撤回授权;
注销超级赞账号时,你在本应用的云存储数据一并删除。

联系我们:<邮箱>
```
