# 故障排查

## 白屏

1. 模拟器的桥调用日志里有没有 `hello`?没有 → SDK 没加载:检查 `<script src="/_sdk/2/sz-webapp.js">` 是不是**同源绝对路径**;
2. 用了前端路由(`/v/12/settings`)刷新白屏 → `superz.json` 设 `"spa_fallback": true`;
3. 资源路径写成了 `/assets/…`(根路径)→ 托管地址在 `/v/<版本号>/` 下面,构建工具的 base 要设成相对路径(Vite 写 `base: './'`);
4. 用了 `eval`、`new Function`、内联 `<script>` → CSP 不放行,把脚本放进独立的 `.js` 文件。

## 「页面跳到了这个小程序以外的地址」

App 网页版在页面每次加载后会问一声(`ping`),SDK 自动回答。8 秒没回答,宿主就当页面跳出了小程序、停止显示。
两种原因:页面真的跳去了别的网站(外链请用 [`openLink`](sdk-reference.md#openlinkurl),先问用户、交系统浏览器);
或者这一页**没引 SDK** —— 托管的每个 HTML 页都要引 `/_sdk/2/sz-webapp.js`,哪怕这一页不调任何方法。
模拟器的日志里会标红提示同一件事。

## CSP 拦截

托管页的 CSP:脚本只能同源;图片、媒体、网络请求只能去同源和你声明的服务器域名;不能嵌 iframe、不能提交表单到别处。
被拦的请求会出现在模拟器日志(「CSP 拦截」)和后台「数据」页的计数里。解决:在「开发设置 → 服务器域名」声明
(只收 https origin),或者把资源打进包里。

声明了还是连不上,看浏览器控制台是不是跨域(CORS)报错:页面和你的服务器不同源,你的服务器要对托管地址(开发者后台应用概览里的「托管地址」,形如 `https://<AppID>.mp.chaojizan.cc`)返回 `Access-Control-Allow-Origin`。

## 验签失败

- 用的是 **URL 解码后**的 value 拼 data_check_string 吗?`user` 的值是 JSON 原文,不要重新序列化;
- 排序是按**键名**的字典序;`hash`、`signature` 不参与;
- AppSecret 刚轮换过?切换前平台用旧的签、切换后用新的签;
- 拿[测试向量](server.md#测试向量)跑一遍你的实现,两种验法都要过;
- 来自 `?sz_mock=1` 的包签名必然无效 —— 本来就该验不过。

## 时钟偏差

服务端判断 `auth_date` 超过 600 秒就拒绝。你的服务器时间偏了几分钟,会出现「刚打开就过期」或「未来的包」。
服务器开 NTP 对时;拒绝时别把「过期」和「签名错」分开告诉前端。

## 4001(能力没申请到)

基础能力所有应用都有(全屏和锁方向也是,2026-09-15 起);`profile` 要在后台申请并审核通过。老版本 App(宿主 2.0)里普通应用调全屏会收到 `fullscreenFailed`,提示用户升级 App 即可。
平台可能收回能力,**下一次调用**就回 4001 —— 每次调用都做好失败处理。

## 4007(版本冲突)

别的设备先改了这个键。取回服务器的版本(`getItemsWithRev`),和你的合并后带新的 `ifRev` 再写;
合不了就两份都留。见[云存储 · 并发](storage.md#并发)。

## 4009(应用被暂停)

应用被平台暂停或当前版本被隔离,宿主会关掉它。原因在后台「审核记录」里,可以在 7 天内申诉。

## 真机上打不开体验版

- 手机上登录的账号的手机号,在「体验者」名单里吗?
- 版本「设为体验版」了吗?
- 安卓想调试页面:「我的 → 设置 → 小程序授权与数据 → 开发者选项 → 小程序调试」,电脑 Chrome 开 `chrome://inspect`。
