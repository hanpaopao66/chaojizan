# 音乐与论坛 · 上线手册(DEV-PROMPTS-41 #377–#382)

和上一批([LAUNCH-40.md](LAUNCH-40.md))一样:**代码一次发完,生产靠开关控制开放范围**。
四个开关缺省全部站在「关」那一边 —— 不经意的一次部署不会把没拿到结论的功能放出去。

合规口径见 [COMPLIANCE-40.md](COMPLIANCE-40.md) 第 17 条(音乐)、第 18 条(论坛):
运营方 2026-09-15 决定**上线即对所有用户开放、都不要求实名**,两条的法务结论仍在等,
要关的话在开关页拨回去即可,不用发版。

## 1. 开关

后台「开关」页(`/admin/flags`)拨,**立即生效、不用发版**。没写过的开关按下表缺省:

| 开关 | 管什么 | 开发 / CI 缺省 | 生产缺省 | 关掉之后 |
|---|---|---|---|---|
| `music_enabled` | 整个音乐(`/music/v1` 全部) | 开 | **关** | 全部回 503「音乐暂未开放」;客户端给空状态、**不给重试按钮** |
| `music_upload_enabled` | 音乐投稿(开通音乐人、建作品、加歌、传音频、提交审核) | 开 | **关** | 只有写那几条 503;要 `music_enabled` 也开着才生效 |
| `forum_enabled` | 整个论坛(`/forum/v1` 全部) | 开 | **关** | 全部回 503「论坛暂未开放」 |
| `forum_post_enabled` | 发帖、回复、引用、编辑 | 开 | **关** | **停笔不关站**:看还能看,写的动作回 503。出事时先拨这一个 |
| `channels_enabled` | 首页金刚区显示哪些业务 | —— | `food,voucher` | 不含 `music` / `forum` 时首页没有这两格(接口是否开着是另一回事) |

- 表里是**没写过**这个开关时的缺省。判「开发」的依据是 `APP_ENV=dev` —— 拼错、留空、
  写成 staging 一律按生产算(`services/flags.music_flag_default`、`forum_flag_default`);
- **两件事要分别拨**:功能闸(上面四个)决定接口通不通,`channels_enabled` 决定首页有没有那一格。
  只拨一半的表现是「首页有入口点进去 503」或者「功能开着但没人找得到」;
- `/config` 的 `features` 把 `music` / `music_upload` / `forum` / `forum_post` 下发给客户端,
  关着的入口客户端直接收起;服务端照样兜底回 503,不指望客户端自觉。

## 2. 迁移

`0142`(平台文案) → `0143`(音乐) → `0144`(论坛)。由 compose 里一次性的 `migrate` 容器跑,
api / sweeper / media-worker 都等它成功再起。**全是新表和新列,不改老数据**。

## 3. compose 和环境变量:这一批没有变化

音频转码复用已有的 `media-worker`(`workers/media.py` 里 `kind == "music_track"` 那条分支),
没有新容器、没有新环境变量、nginx 不用改。上一批部署好的机器直接发就行。

## 4. 容量

- 音频源文件进**私密桶**,转完就删源;成品出 1–2 档 AAC(`std` 128k;源码率 ≥192k 或读不出码率时再出一档 `hq` 256k),
  响度统一到 −14 LUFS;单首 5 秒–20 分钟。按 4 分钟一首估:std 约 3.8MB,std+hq 约 11MB;
- 论坛只有图片,走已有的公开图那条路(和视频封面、聊天图同一个桶和同一套签名规则)。

## 5. 回退

1. **先拉开关**:出问题的那一块关掉,立即生效 —— 论坛先拨 `forum_post_enabled`(停笔不关站),
   不够再拨 `forum_enabled`;音乐同理先 `music_upload_enabled`;
2. 代码回退:`scripts/deploy_server.sh` 部署上一个版本;
3. **迁移不回滚** —— 新表新列对老代码是透明的,`alembic downgrade` 会删掉用户已经发出去的帖子和上传的歌,不做。

## 6. 上线核对

- [ ] `docker compose ps`:migrate 退出码 0,`alembic_version` = `0144`;api、sweeper、media-worker、minio、nginx 在跑
- [ ] `/health` 的 version 是这次发的 tag;`/config` 的 `features` 里有 `music`、`forum` 两个键
- [ ] 开关页四个闸按上面的决定拨好;`channels_enabled` 勾上「音乐」「论坛」,`/channels` 能看到这两个 key
