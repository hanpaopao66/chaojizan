# 消息与视频合规清单(DEV-PROMPTS-40 #374)

**这份清单不下结论。** 每一条写的是:我们理解的相关规定(引用都要法务核对原文和最新修订)、代码里现在怎么做的、
要法务回答的问题。和小程序那份([MINIAPP-COMPLIANCE.md](MINIAPP-COMPLIANCE.md))一个写法。

「上线前卡不卡」是工程侧的判断,供排期参考,也要法务确认。**视频上线卡在许可证上**:生产缺省把视频、投稿、通话、机器人
全部关着(见 [LAUNCH-40.md](LAUNCH-40.md) §1),拿到结论之前谁也不能不经意地打开。
视频和投稿已由运营方在 2026-09-15 知情后先打开(第 5 条);通话、机器人仍然关着。
