# 官方精品小游戏:方块原野 / 星火牌局 / 突击时刻 / 瓜田防线

平台已有的官方小程序是**轻量**的:记事本、2048、贪吃蛇、方块消除、扫雷、五子棋、萌兽三路。
这一批做四款更重的**原创单机游戏**,把「小程序里的游戏能做到什么程度」立成四个参考实现,
也给第三方开发者看四种技术路线。统一质量标准见 [GAME-STANDARD.md](GAME-STANDARD.md);
塔防的设计规格见 [GAME-TOWER.md](GAME-TOWER.md)。

**选的是品类,不是作品。** 四款分别对标「体素沙盒 / 回合制卡牌对战 / 战术射击 / 固定路线塔防」,
名称、规则、数值、地图、卡牌、美术、音效全部原创;没有使用任何商业游戏的商标、素材、角色或界面,
源码与「关于」页里也不出现商业游戏的名字(见每款 `ASSETS.md` 与 listing 的原创性说明)。

四款都遵守平台既有边界:**免费、无内购、无广告、无排行榜、单机、不申请敏感能力**;
数据只存超级赞云存储(隐私政策逐款写清),美术全部程序化生成或内联 SVG,音效/音乐全部 WebAudio
合成,CSP 里没有外部请求。

## 统一标准与工具

四款按同一份 [GAME-STANDARD.md](GAME-STANDARD.md) 做策划/数值/画面/音效/交互无障碍/工程/测试/发布。
配套工具已经进仓库:

```sh
cd miniapps
npm run typecheck:<app>              # 只查这个应用(+ shared / SDK)
npm run test:<app>                   # 纯函数单测(全量:node scripts/test.mjs)
npm run build:<app>                  # vite 构建到 <app>/dist/pkg
bash ../scripts/build_miniapp.sh <app>          # 全量 tsc + 本应用单测 + 可复现 zip
node scripts/check_miniapp_meta.mjs <app>       # 静态:结构/元数据/无外部素材/调试钩子/包体
node scripts/qa_miniapps.mjs <app>              # 无头 Chrome:渲染/交互/暗色/fps/console/外链
```

- 纯逻辑与界面分开;存档统一走 `SaveSlot`(本机秒开 + 云存储,按 open_id 隔离);
- 主题走 `base.css` 宿主 CSS 变量 + `followTheme()`,亮暗两套;尊重 `prefers-reduced-motion`;
- `shared/src/ui.ts` 的 `Overlay` 统一做**焦点陷阱 + 背景 inert**:弹层打开时 Tab/读屏不会穿到
  后面的游戏里(四款新构建都包含);
- 切后台暂停 + 立刻存档(`hostGame`),开始游戏时请求全屏并按 `superz.json` 锁方向;
- `check_miniapp_meta.mjs` 接进 `make analyze` 与 CI;`qa_miniapps.mjs` 是发布前手动门禁。

## 方块原野(`miniapps/sandbox/`)

第一人称体素沙盒。程序化生成一座 128×128 的小岛(海面、沙滩、草原、石丘、树),用准星挖方块、
把挖到的方块放到别处,搭房子、搭桥、在山上开洞;九种方块、约八分钟一轮的昼夜。没有怪物、
没有合成、没有任务、没有联机 —— 就是一座岛。

- **渲染**:Canvas 2D 的 DDA 光线投射,程序化方块纹理(每面 3 个变体)、距离雾、面的明暗、
  水面波纹/反光、天空渐变 + 云/星星/日出日落、挖掘裂纹与碎屑粒子。
- **交互**:挖(按住,不同方块硬度不同)/ 放;热栏 9 格;桌面鼠标锁定 + WASD,手机左下摇杆 +
  右侧拖拽视角 + 挖/放/跳。手感有土狼时间、跳跃缓冲、自动上台阶、放置冷却,并有帧率无关测试。
- **1.1 新增**:13 个成就 + 统计面板;4000 格上限的清理出口(撤销最近 100 / 恢复原始岛);
  按材质脚步/挖放声、水下低通、昼夜环境声;世界生成与 1.0 **逐字节一致**(golden 测试,
  旧档的树屋不会悬空);云统计合并防覆盖、v1 档迁移不抬高存档时间。
- **存档**:种子、稀疏改动(上限 4000 格)、位置朝向、背包、世界时间;统计/成就存 `best`。
- **诚实边界**:没有怪物、合成、多人、任务;成就里的「一口气/夜行者」等按本局判定;
  清理只支持「撤销最近 100」与「恢复原始岛」。

## 星火牌局(`miniapps/cards/`)

回合制卡牌对战,和电脑打。双方英雄 30 血,能量每回合上限 +1(最多 10),出随从站场、用法术解场,
把对面英雄打到 0。3 套各 30 张的原创预组卡组、36 张原创卡。

- **规则**:抽牌/疲劳、手牌 10、场上 7、召唤失调、嘲讽、冲锋、圣盾、战吼、亡语、固定死亡结算顺序;
  后手第一回合有一次性「幸运币」+1 能量。
- **1.1 新增**:第三档「休闲」难度(只调 AI)、12 个成就、36 张卡图鉴(每张卡独立内联 SVG 徽记 +
  稀有度)、首局内联提示、按阵营的战场主题、粒子/星级结算、关键字音效与三套合成 BGM。
  用固定种子 **9000 局**模拟重新平衡:玩家视角胜率 休闲 75.9% / 标准 49.9% / 困难 27.1%,
  三套牌 45–54%,不卡死;1.0 进行中的局旧档可以继续(新字段缺省,不丢档)。
- **AI**:启发式评分 + 有限预算的斩杀搜索(超预算回退),固定种子可复现。
- **存档**:整局状态(牌库/手牌/场面/能量/回合/种子)可续 + 战绩/成就/图鉴;坏档容错。
- **诚实边界**:单机 AI、固定预组、不能自建卡组;无英雄技能/护甲/武器;无多人/排行榜/内购/广告/开包抽卡。

## 突击时刻(`miniapps/tactical/`)

2D 俯视、回合制拆弹的战术射击。整张地图一屏可见:你是进攻方,75 秒内清掉或绕开 3 名 AI 守卫,
到 A 或 B 点按住 2.5 秒安放炸弹,再守住 30 秒;先赢 2 回合者获胜。

- **地图**:两张 44×26 地图(旧仓库 / 霓虹夜市),不同布局与亮暗配色;守卫只有在你视线内才画出来,
  失去视线留 1 秒「最后已知位置」。
- **战斗**:步枪 + 副武器手枪(Q / 触屏切换,弹药独立);步枪 4 枪、手枪 3 枪一个;
  连射散布、换弹、瞬时 hitscan;无爆头/护甲/血腥表现。
- **1.1 新增**:第二张地图、副武器、6 个成就、训练场(不记战绩);TTK 与三档难度重调并写成
  平衡测试(固定种子:休闲 3/3 胜、标准 3/3、困难 2/3;站着不还手存活 12.2s/5.9s/3.8s);
  两张地图 × 亮暗配色、行走摆动/枪口辉光/曳光/弹壳/火花、空间化音效(PannerNode)+ 合成 BGM;
  档案升 v2(v1 自动迁移,未来版本只读不回写);宿主返回键分派(回合结算→重新展示,
  整场结束→回首页,暂停→继续),不会再把人困在已结束的一局。
- **存档**:战绩/成就/设置;不保存进行中的比赛(回合制,回首页开新局)。
- **诚实边界**:2D 俯视单机,不是 3D 射击;无多人、无开箱/饰品、无内购/广告/排行榜;
  不涉及真实武器品牌或真实地图。

## 瓜田防线(`miniapps/tower/`)

固定路线塔防:虫子从地图边缘沿土路爬向田中央的大西瓜,你在路边木桩上造塔、升级、卖塔,
撑过全部波次就赢。**12 关三主题**(菜园白天 / 果园黄昏 / 虫巢月夜)+ 无尽模式(通关第 12 关解锁)。

- **塔**:7 种 × 3 级 —— 豆荚炮(单体)、冰霜铃(减速/冻结)、火焰椒(溅射/灼烧)、
  闪电藤(链电)、毒蘑菇(毒/死亡毒云)、瓜藤弓(远程/穿甲)、金盏花(产金);
  升级面板显示伤害/攻速/射程与全部特性,卖出返 70%。
- **虫**:9 种含 3 只 Boss —— 青虫、跳蚤、甲虫(护甲)、飞蛾/毒蜂(飞行)、治疗蛹、分裂蚁、巨虫;
  飞行虫第 7 关起登场,**豆荚炮/毒蘑菇只打地面**,后期必须混塔。
- **平衡**(`test/balance.test.ts` 固定种子):按每关 `recommend` 的**混塔参考策略 12 关全部
  满血 3 星**;纯豆荚炮第 1–6 关能 3 星、第 7–12 关全部 ≤2 星;无尽模式混塔撑过 20 波。
  `recommend` 同时用于新手提示,不存在死字段。
- **流程**:每波前 3 秒准备,可「提前召唤」+5 金币;1x/2x、暂停;12 个成就、12 关解锁进度。
- **存档**:进行中的一局(紧凑格式,300 虫 + 800 待出怪最坏情况约 29KB,<64KB)+
  星级/成就/无尽最高/设置;两设备合并取高/并集。
- **诚实边界**:单机、无广告/内购/排行榜/联机;美术与 BGM/SFX 全部程序化合成;
  没有体力、签到、抽卡。

### 上线前独立审查(2026-10-18)

单测全绿不等于玩得通 —— 两轮只读审查(逐文件 + 真实浏览器点按)都抓到过真问题,记在这里:

**1.0 首发前(三款)**
- **突击时刻 P0:安放炸弹完全不可能**。`KeyE` 只 `preventDefault`、没进按键集合;移动端
  `#btn-plant` 从来没被显示。单测直接给引擎传 `interact:true`,43 条里一条都没照到。修完后
  用真实键盘走位清守卫 → 按住 E 安放 → 30 秒爆炸拿回合;生产包无调试钩子。
- 突击时刻另修:重开叠 rAF、整场结算前退出丢战绩、战绩合并自相矛盾、Esc 关暂停又弹回;
- 星火牌局:结算弹层按宿主返回卡在已结束牌桌、Esc 重复处理、「点空白取消」没实现、
  困难档斩杀搜索无上限(合法局面实测 59 秒)。

**1.1 发布前(三款精修 + 塔防)**
- **瓜田防线 P0:存档判坏**。毒/灼烧/治疗蛹让敌人 hp 变小数,存档校验按 int 判坏,第 5 关后
  整局丢失;改成紧凑存档 + 有限数值校验,300 虫 + 800 待出怪最坏情况约 29KB,浏览器实测
  中毒后刷新「继续游戏」正常。另修:返回键、首页隐藏对局仍在 DOM(可 Tab/读屏)、建造面板焦点、
  塔面板缺少特性说明、平衡测试太弱(纯豆荚炮 12 关全 3 星)、「不联网」与云存储文案矛盾、
  关闭按钮 36px、飞虫没有对空规则。
- **突击时刻 P0:结算弹层被宿主返回键弄成死局**(回合/整场结算被隐藏后不能继续也不能回首页,
  只能刷页面);修成按状态分派;另修静音再开 BGM 不恢复、档案 v1→v2 迁移与未来版本只读。
- **星火牌局 P1:1.0 进行中的局被丢**(新字段 `coin` 让旧 GameState 读档返回 null);
  补缺省并回写升级 + 1.0 形态存档单测;另修结算页按设置键被「关于」覆盖、暂停层下 BGM 续响。
- **方块原野 P1:同 seed 旧岛地形变了**(改出生点留空半径挪动了 RNG 流,旧档树屋会悬空);
  恢复 1.0 参数并加 golden 回归(8 个 seed 逐字节一致);另修云统计被本机旧档覆盖、
  v1 迁移抬高存档时间。
- 顺手把弹层无障碍修到 `shared/src/ui.ts`:焦点陷阱 + 背景 `inert`,四款新构建一起受益。
