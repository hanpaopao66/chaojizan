电脑版 · 用户端
Windows
Windows 10、11，64 位

解压后打开 chaojizan 文件夹，双击 chaojizan.exe。第一次打开如果弹出「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」：我们没有买代码签名证书，系统认不出发行方。

下载 zip
macOS
macOS 13 及以上，Apple 芯片和 Intel 芯片的 Mac 都能用

打开 dmg，把「超级赞」拖进「应用程序」。我们没有做苹果的开发者签名和公证，第一次打开会被系统拦下：打开「系统设置」→「隐私与安全性」，往下翻，点「仍要打开」，再点「打开」。macOS 14 及更早的系统，也可以在「应用程序」里右键点「超级赞」→「打开」。

下载 dmg
Ubuntu
Ubuntu 22.04、24.04，64 位（x86）

deb 包：在下载目录里执行 sudo apt install ./chaojizan-linux-x64.deb，装好后在应用列表里找「超级赞」。tar.gz：解压后运行 chaojizan/chaojizan；发语音消息要系统里有 pulseaudio-utils 和 ffmpeg（用 apt 装 deb 时会一起装上）。
