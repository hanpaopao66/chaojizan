超级赞 隐私政策(门店点餐版)

更新日期:2026-10-27
生效日期:2026-10-27
运营主体:陕西爱卡斯科技有限公司(下称"我们")

本政策说明你使用超级赞 App(门店点餐版)时,我们如何收集、使用、共享、存储和保护你的个人信息,以及你享有的权利。我们只收集提供点餐服务所必需的最少信息,不出售你的任何个人信息。

一、我们如何收集和使用个人信息(按使用场景)

1. 注册与登录:手机号(必需)。用于创建账号、短信验证码登录、订单联系;
2. 下单与配送:收货地址、联系人、联系电话、位置信息。用于判断收货地址是否在门店配送范围内、计算配送费、完成配送。位置只在你选择收货地址、查看门店距离时获取,不在后台获取;
3. 头像与昵称(可选):用于展示你的个人资料,可随时修改;
4. 支付:订单号与应付金额经由微信支付完成收款。支付账户、银行卡号等由微信支付处理,我们不收集、不留存;
5. 售后、食安投诉与客服:会话记录、工单内容,以及你主动从相册选取的凭证图片。用于处理你的咨询、售后和投诉;
6. 评价:你给出的评分、文字和从相册选取的配图,会在门店页向其他顾客展示(显示昵称,不显示手机号);
7. 发票:如你通过客服申请开票,收集发票抬头、税号与接收邮箱,仅用于开具发票;
8. 交易记录:订单与支付、退款信息。用于订单查询和售后凭证,并按《电子商务法》等法律要求留存;
9. 使用行为记录(页面浏览、搜索词):仅用于改进产品。自建统计、不接入第三方分析服务、不采集设备指纹,注销账号时删除。

二、第三方 SDK 与第三方服务信息公示

为实现推送、支付、地图等功能,我们接入了以下第三方 SDK 与服务,只在实现功能所必需的范围内向其提供信息,并要求其依法保护你的信息。

(一)App 内嵌第三方 SDK(均在你同意本政策之后才初始化)

· SDK 名称:极光推送 JPush
第三方主体:深圳市和讯华谷信息技术有限公司
涉及个人信息:设备标识信息(如 Registration ID、设备厂商型号、系统版本)、网络信息
使用目的与场景:向你推送订单状态通知
隐私政策:https://www.jiguang.cn/license/privacy
· SDK 名称:腾讯地图 SDK(Android 地图 SDK / iOS 地图 SDK)
第三方主体:深圳市腾讯计算机系统有限公司
涉及个人信息:网络类型、设备型号、屏幕密度与尺寸、操作系统及版本、IP 地址;Android 另有 OAID;iOS 另有 IDFV、位置信息(可选)
使用目的与场景:在地图上选择收货地址、查看配送位置
隐私政策:https://privacy.qq.com/document/preview/a10a8634f237464da9a95f4f07e73e40
· SDK 名称:Google ML Kit 条码扫描(只在 Android 安装包内)
第三方主体:Google LLC
说明:这个组件随扫码功能一起打包进安装包。门店点餐版不提供扫码功能,不会初始化这个组件,也不会通过它收集任何信息

(二)第三方服务(经我们的服务器调用,不在 App 内嵌入 SDK)

· 微信支付(财付通支付科技有限公司):完成订单支付与退款。传输订单号、金额;你的支付账户信息由微信支付处理,我们不接触。隐私政策见微信支付服务协议;
· 高德开放平台(高德软件有限公司):收货地址搜索联想。你输入的搜索关键词与所在城市经我们的服务器转发查询,不向其提供你的账号信息。隐私政策:https://lbs.amap.com/pages/privacy/;
· 腾讯位置服务 WebService(深圳市腾讯计算机系统有限公司):收货地址所在城市解析、配送距离与时长计算。经我们的服务器向其发送坐标请求,不向其提供你的账号信息。隐私政策:https://privacy.qq.com/document/preview/4cf61fd47f584dae83758bb0f11c1533

除上述公示外,我们未接入其他收集个人信息的第三方 SDK。如后续新增,我们将更新本政策并重新征求你的同意。

三、信息的共享、转让与公开披露

1. 为完成配送,你的收货地址、联系电话与订单内容会提供给门店及其配送人员,仅限履行该订单所必需;
2. 我们不会向任何第三方出售你的个人信息;除本政策载明与法律法规要求外,不对外共享、转让、公开披露;
3. 涉及合并、分立、解散等情形时,我们会要求承接方继续受本政策约束,否则重新征求你的同意。

四、信息的存储与保护

1. 你的个人信息存储于中华人民共和国境内的服务器,不出境;
2. 传输全程 HTTPS 加密,敏感信息加密存储、展示时脱敏;
3. 保存期限:账号信息保存至你注销为止;交易与账务数据按《电子商务法》等要求自交易完成之日起保存不少于三年,超期后删除或匿名化;使用行为记录在你注销时立即删除;
4. 发生个人信息安全事件时,我们将依法及时告知你并向监管部门报告。

五、你的权利

1. 查询与更正:在「我的」页可随时查看、修改昵称、头像、收货地址;
2. 删除:可自行删除收货地址;行为记录随注销删除;
3. 注销:在「我的 → 设置 → 注销账号」自助办理。注销后账号将被匿名化,无法恢复;有进行中的订单时需先完结;
4. 撤回同意:你可以在手机系统设置中随时关闭位置、相册、通知等权限,撤回后不影响此前基于授权的处理,也不影响你使用不依赖该权限的其他功能;
5. 投诉与响应:通过 App 内客服、邮箱 support@chaojizan.cc 或电话 15231109698 联系我们,我们将在 15 个工作日内答复。

六、未成年人保护

本 App 不面向 14 周岁以下未成年人提供服务;如发现误收集了未成年人信息,监护人可联系我们删除。

七、政策更新

政策如有重大变更,我们将在 App 内提示并重新征求你的同意;历史版本可向客服索取。
