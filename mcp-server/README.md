# 超级赞 MCP 服务：用 AI 助手点餐、发视频、发布小程序和小游戏

把超级赞接进你的 AI 助手（Claude，以及任何支持 MCP 的客户端），然后用一句话让它办事：

- **点餐**：「帮我在公司附近找一家 30 块以内的牛肉面，算好配送费，下单」
- **发视频**：「把桌面上的 旅行.mp4 发到超级赞，标题叫《成都一日》，分区选生活」
- **发布小程序和小游戏**：「把 ./dist 作为 1.2.0 传到我的小游戏，提交审核；审核过了就发布上线」

## 先说它做不到什么

| | 能做 | 做不到 |
|---|---|---|
| 点餐 | 找店、比价、算配送费、**创建待支付订单**、查进度 | **付款**。付款那一下永远在你自己的 App 里，由你按 |
| 发视频 | 从你电脑上的文件建稿、传片、传封面、提交审核、查审核进度 | **过审**。提交后是「审核中」，由平台的人审，通过后才公开；删稿、点赞、评论也做不了 |
| 发布小程序和小游戏 | 建应用、填上架信息、传包、设体验版、提交审核、撤回、**审核通过后**发布上线、回滚 | **过审**。没过审的版本发布不了；删应用、改密钥和域名、加体验者、实名认证、签开发者规则也做不了 |

所以即使令牌泄露：对方能替你创建一张 15 分钟后自动关闭的待付单，**但花不掉你一分钱**；
能替你投一条稿、传一个包，**但公开之前都要过平台的人审**；删不掉你的任何东西。

这些不是没做完，是有意的：动钱、过审、删了回不来的事，判断权留给人。
服务端也不靠自觉 —— 令牌签发时勾了哪几项，就只放行那几项的白名单，其余一律 403
（代码在 [`server/app/security.py`](../server/app/security.py) 的 `AGENT_SCOPES`）。

## 三步接上

### 1. 签一个令牌

- **点餐、发视频**：超级赞 App →「我的 → 设置 → AI 助手」→ 签发，勾上要给助手的权限。
- **发布小程序和小游戏**：开发者后台 [`/dev/`](https://chaojizan.cc/dev/) →「账号 → AI 助手」→ 签发。

令牌的明文**只显示这一次**，马上复制。只勾需要的那一项 —— 能做的事越少，丢了损失越小。
一个账号最多同时挂 10 个；用不到的在同一页吊销，下一次调用就失效。

### 2. 把它接进你的 AI 客户端

MCP 服务只有一个文件，只用 Python 标准库（3.9 以上），不用装任何依赖：

```bash
curl -O https://raw.githubusercontent.com/hanpaopao66/chaojizan/main/mcp-server/server.py
```

**Claude 桌面版**：打开配置文件（macOS 是 `~/Library/Application Support/Claude/claude_desktop_config.json`，
Windows 是 `%APPDATA%\Claude\claude_desktop_config.json`），加上这一段，然后重启 Claude：

```json
{
  "mcpServers": {
    "superz": {
      "command": "python3",
      "args": ["/绝对路径/server.py"],
      "env": {
        "SUPERZ_API": "https://chaojizan.cc",
        "SUPERZ_AGENT_TOKEN": "刚才复制的那串"
      }
    }
  }
}
```

**Claude Code**：

```bash
claude mcp add superz -e SUPERZ_API=https://chaojizan.cc -e SUPERZ_AGENT_TOKEN=刚才复制的那串 -- python3 /绝对路径/server.py
```

**其他客户端**（Cursor、Cline 等）：配置格式一般和上面的 JSON 一样，command 填 `python3`，
参数填 `server.py` 的绝对路径，两个环境变量照填。自己搭了实例的，把 `SUPERZ_API` 换成你的域名。

### 3. 先干跑一次

```bash
SUPERZ_API=https://chaojizan.cc SUPERZ_AGENT_TOKEN=xxx python3 server.py --selftest
```

它会告诉你这个令牌能做哪几件事，并把能用的只读工具各打一遍。**不会下单、不会投稿、不会传包。**
都打勾了再去客户端里用。

## 然后这样说

### 点餐

- 「我在天府三街地铁站，找一家评分高的面馆，看看菜单」
- 「这两家送到我这儿各多少配送费？」（助手用的是「只算价不下单」的工具）
- 「就要这家的二两牛肉面加个蛋，送到公司前台，下单」

助手下完单会告诉你订单号。**打开超级赞 App →「我的订单」确认并付款**；15 分钟不付自动关闭，不扣钱。

### 发视频

- 「把 ~/Movies/旅行.mp4 发到超级赞，标题《成都一日》，分区选生活，标签：成都、旅行，封面用 ~/Pictures/cover.jpg」
- 「先传上去存草稿，别提交」（助手会建好草稿等你确认）
- 「刚才那条审核过了没有？被驳回的话原因是什么？」

视频只收 mp4 / mov / m4v / webm / mkv，最大 1GB、最长 30 分钟；封面收 jpg / png / webp。
提交后先转码（「处理中」），转完进「审核中」，审核通过才公开。

### 发布小程序和小游戏

- 「我的小程序有哪些？各自线上是哪一版？」
- 「建一个小游戏，叫《方块消消》，分类休闲益智」
- 「把 ./dist 作为 1.2.0 传到《方块消消》，更新说明写『修了存档丢失』，设成体验版」
- 「提交审核，给审核员的备注：打开即玩，不用登录」
- 「审核过了就发布上线」「线上这版有问题，回滚到 1.1.0」

给文件夹时，助手会先打包：根目录要有 `index.html` 和 `superz.json`（包的格式见
[快速开始](https://chaojizan.cc/developers/quickstart)）。**给构建产物那个文件夹，不是源码目录。**
提交审核前，开发者账号要已经认证、签过开发者规则 —— 这两件要你自己在开发者后台做。
更细的发布流程见官网开发者文档的[用 AI 助手发布](https://chaojizan.cc/developers/ai-publish)。

## 你电脑上的文件

MCP 服务跑在你自己的电脑上，读得到你的文件。为了不被网页里的一句话诱导着把别的文件传出去：

- 发视频只认视频和封面图片，传小程序包只认 zip 或文件夹；**先看扩展名，再看文件头**，
  改了扩展名的私钥、文档一律不传，在发请求之前就拦下；
- 给文件夹打包时，只装小程序包允许的那些扩展名（html、js、css、json、图片、字体、音视频、wasm 等）；
  `.env`、`.git` 这类点开头的文件和目录、`node_modules`、符号链接一律跳过，跳过了什么会告诉你。

大多数 AI 客户端在调用工具前会让你确认一次。发视频、提审、发布上线这几步，确认前看一眼参数。

## 令牌丢了怎么办

在签发的地方（App「设置 → AI 助手」或开发者后台「账号 → AI 助手」）**吊销**它，下一次调用就是 401。
同一页能看到这个助手做过的每一次调用：方法、路径、结果、时间 —— **不存请求内容**（那里面是你的地址和手机号）。

## 没有沙箱

在正式环境试，产生的都是真东西：`create_pending_order` 会生成**真实的待支付订单**（不付款 15 分钟后
自动关闭、不扣钱，但商家端会看到它闪一下）；`publish_video` 会生成真实的稿件进审核队列；
传包、提审也一样。想放心试，用草稿（`submit=false`）和体验版。

## 出错了看这里

| 看到 | 意思 | 怎么办 |
|---|---|---|
| 401 令牌已被吊销 / 已过期 | 令牌不能用了 | 重新签一个 |
| 403 AI 助手令牌不能做这件事 | 这个令牌没这项权限，或者这件事本来就不给助手做（付款、删稿、改密钥……） | 照提示去签一个勾了那一项的令牌；付款这类只能自己做 |
| 这个 AI 助手令牌没有「…」权限 | 同上，MCP 在发请求前就拦下了 | 同上 |
| 503 视频投稿暂未开放 | 平台还没开放视频投稿 | 等开放 |
| 包没有通过校验 | 平台逐条校验没过，报告里写着哪一条 | 按报告改完重传 |
| 提交审核被拒：没认证 / 没签规则 | 开发者账号还差这两步 | 去开发者后台做完 |
| 连不上 … | 地址不对或网络不通 | 检查 `SUPERZ_API` |

## 为什么没有依赖

只用 Python 标准库。这是开源项目，少一个依赖少一份供应链风险，
而一个最小的 JSON-RPC over stdio 实现只要几百行。测试：`python3 -m pytest mcp-server -q`。
